# Valoranto Five Planner

A shared VALORANT map and agent planning board for a five-player team.

## Features

- Shared team composition and comfort pick planning
- Live sync between PC and mobile browsers
- Agent role filtering with role icons
- Tactical map pins, drawing tools, site labels, rotation, and zoom
- Mobile panel collapse controls
- Mobile pinch zoom on the map

## Local Run

```powershell
npm start
```

Open:

```text
http://127.0.0.1:5173
```

## Render Deploy

This app is ready for Render Web Service deployment.

- Build command: `npm install`
- Start command: `npm start`
- Runtime: Node

Only the owner needs to log in to Render. Friends can open the deployed URL without logging in.
